# 🌴 Elysian Oasis — Hotel Website

Elysian Oasis is a modern and responsive hotel website designed to provide visitors with an elegant and user-friendly experience. The website showcases hotel rooms, services, pricing, gallery, team members, blog posts, and a booking/availability section.

## 🌐 Project Overview

**Elysian Oasis** is a front-end hotel website project developed using HTML, CSS, JavaScript, and Bootstrap 5.

The website focuses on:

* 🏨 Hotel information
* 🛏️ Room and suite showcase
* 📅 Booking/availability interface
* 🧖 Hotel services
* 👥 Team section
* 🖼️ Image gallery
* 💰 Room pricing
* 📝 Hotel blog
* 📱 Responsive design

## ✨ Features

### 🏠 Home

* Full-width hero slider
* Welcome section
* Hotel introduction
* Booking/availability form

### ℹ️ About

* Hotel introduction
* Description of Elysian Oasis
* Explore section

### 🛏️ Rooms

The website showcases different types of rooms and suites:

* Executive Suite
* Honeymoon Suite
* Presidential Suite

Each room includes:

* Room image
* Description
* Price per night
* Book Now button

### 🧖 Services

Hotel services are presented through a dedicated services section with images and icons.

### 👥 Team

A dedicated section for introducing hotel team members.

### 🖼️ Gallery

A responsive image gallery showcasing the hotel and its surroundings.

### 💰 Pricing

Different room packages and their facilities are displayed with pricing information.

### 📝 Blog

The website includes a hotel blog section for displaying posts and visitor information.

### 📱 Responsive Design

The website is designed to work across:

* Desktop
* Laptop
* Tablet
* Mobile devices

## 🚀 How to Run

This is a static front-end project, so no server or database is required.

### Option 1 — Open Directly

Download or clone the repository and open:

```text
index.html
```

in your web browser.

### Option 2 — VS Code Live Server

1. Open the project in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

The website will then open in your browser.
